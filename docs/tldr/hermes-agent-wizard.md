# hermes-agent-wizard

> Interactive TUI launcher for the Hermes Agent.
> More information: <https://github.com/danindiana/hermes-agent-wizard>

- Start the wizard:
  `hermes-agent-wizard`

- Display verbose help:
  `hermes-agent-wizard --help`

- Navigation:
  `Tab` to switch tabs, `Arrows` to select actions, `Enter` to run, `q` to quit
